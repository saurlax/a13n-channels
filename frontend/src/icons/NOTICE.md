# Channel icons

- WeChat, Discord, Telegram, and MQTT use [Simple Icons](https://github.com/simple-icons/simple-icons) (CC0). The artwork is displayed in the platforms' brand colors.
- Slack uses the [SVG Logos Slack icon](https://github.com/gilbarbara/logos/blob/main/logos/slack-icon.svg) (CC0).
- Feishu uses the [Gitea Feishu icon](https://github.com/go-gitea/gitea/blob/main/web_src/svg/gitea-feishu.svg) (MIT).
- DingTalk uses the [Netnr.Login DingTalk icon](https://gs.zme.ink/static/login/dingtalk.svg) (MIT).
- WeCom uses the [transparent color logo published by Tencent](https://www.tencent.com/wp-content/uploads/2022/12/wecom-1.svg).
